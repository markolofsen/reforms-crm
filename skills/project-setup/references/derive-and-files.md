# Derived Quick Links (step 2) and the files a new project gets (step 5)

## Quick Links
Quick Links: when `notion.teamspace_id` is known, search the teamspace for the pages and databases the owner wants in the menu, fetch each result before recording it, and prepare a `## Links` table. Use `notion:<role>` for a database role already declared under `## Notion databases`, `notion:<32 hex id>` for another Notion page or database, and `https://` only for a named external site. Preserve the owner's order and use `Under` for one level of nesting; never copy page prose into the table. Add one `Sites` row per brand domain when the brand names a site. If the teamspace id or a page id is not available, leave that row out and report it instead of inventing a URL.

## The files
`projects/<slug>/project.md` in the layout of doc 16 section 3, with the `kind` row right after `schema` (`By=owner` if the owner chose it, `default` for `generic`), `knowledge/files/` empty. Add the validated `## Links` table after `## Notion databases` when the owner supplied destinations; without the table the menu is empty. Copy the starter workflows: `cp -R app/projects/_template/workflows projects/<slug>/workflows` (ten Draft playbooks the project then owns; none is picked by an agent until the owner sets `status: Active`; `hub workflows list <slug>`). Copy the starter follow-up sequences the same way: `cp -R app/projects/_template/sequences projects/<slug>/sequences` (two Draft files; the owner enrols clients in the admin; `hub sequences check <slug>`). Copy the kind's starting taxonomy: `hub project kinds <kind>` prints it as JSON; write its `audiences`, `category` and `stages` as `## <axis>` sections of `knowledge/taxonomy.md` (format: doc 16 section 5, "Taxonomy"; skip an empty axis). The project owns the file from then on. Then `hub dev init <slug> --apply`: the project's own `@dev/` kanban for its development plans (dry run first; it never overwrites). Leave `status: draft`. Outside `## Notion databases` write no `- key: value` list items; `## Links` is a table, never a list.
