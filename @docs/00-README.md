# reforms-crm @docs

A local, manual-first workflow. The owner starts a Claude Code session (`hub agent <project>`) or Claude Desktop and hands it
ONE instruction; the agent reads a project's mail (Mail.app through mail-mcp, or read-only IMAP), updates the project's Notion CRM
through the session's connector and leaves UNSENT drafts. Nothing runs in the background and nothing is sent by the agent.
Notion token, mail login and the Telegram poller are optional and off by default; operation needs no Notion integration token.

**Two layers.** Everything in this repository is **core** (universal design, code, skills, install). One owner's projects,
history and secrets are an **instance**, kept outside it and selected with `HUB_HOME`. Rule, path table and instance steps: [LAYERS.md](LAYERS.md).
A new document goes in `core/` only if it names no specific client, project, mailbox or person.
