# {{NAME}}

An **instance** of the reforms-crm core: the data of one business owner's projects, with no code. The core is the `core/` submodule, pinned in `core.version`.
Keep this repository private: it holds client facts. Secrets live only in `state/secrets/` (git-ignored). The instance owns its data, config, secrets, backups and skills (linked into its own `.claude/skills/`); nothing goes in your home folder but the optional `hub` shortcut (`core/@docs/core/08-local-app-stack.md`).

## What is here

| Path | What |
|---|---|
| `projects/<slug>/` | one folder per project: `project.md`, `knowledge/`, `sequences/`, `workflows/`, `@dev/` (the project's own development kanban: `./run.sh dev init <slug> --apply`) |
| `@dev/` | this owner's own kanban (`active/`, `blocked/`, `planned/`, `completed/`, `decisions/`, `_archive/`) |
| `@docs/custom/` | this owner's own notes and live facts |
| `@refs/` | reference material of this owner |
| `config/lead-forms.json` | the public lead forms `./run.sh doctor --only Leads` checks (`core/@docs/core/22-lead-forms.md`); committed |
| `package.json`, `pnpm-workspace.yaml`, `turbo.json` | only when the instance has its own `apps/` or `packages/`: generated by `./run.sh workspace init --apply` (decision 0018), regenerated by `core update` |
| `core.version` | the core version this instance runs on (the only place it is stated) |
| `state/`, `data/`, `config/config.json`, `.mcp.json`, `.claude/skills/` | working state and generated files; git-ignored |

## Daily use

Run everything from this folder (the command finds the instance, and runs the pinned `core/`):

```sh
./run.sh                           # the menu: agent session, admin, check, mail filters
./run.sh doctor                    # setup checks, instance-vs-core check, project table
./run.sh up                        # the admin: what the agent did, live; you send (ports: admin_port / api_port in config/config.json)
./run.sh agent <project>           # a Claude Code session bound to one project (--cli codex for Codex); say «настрой проект <project>» the first time
./run.sh send policy <project>     # the project's send policy; only you change it (set <project> <field> <value>)
./run.sh core update               # list core versions; --apply <tag> moves the pin, --branch main follows main
```

The admin always carries the agent (a terminal dock on the right edge, Ctrl+`; no switch, decision 0032). Switches in `config/config.json`: `agent.default` picks Claude or Codex; `agent.unattended: true` drops the prompts and turns the OS sandbox on (`core/@docs/core/24-terminal.md`).

The admin's header shows `name` from `config/config.json` ("Hub" when empty) and, when `logo` names an image file (svg, png, jpg or webp; a relative path is read from `config/`), that logo; otherwise a monogram. `./run.sh doctor` warns when the logo file is missing.

Joining as a teammate: `git clone --recurse-submodules <this repo>`, then `./run.sh setup` (it checks out the pinned core, installs the dependencies, and lists what is personal and still missing on your Mac). Keep this folder on a local disk, never in Google Drive, iCloud or Dropbox. The whole workflow: `core/@docs/setup/team.md`.
