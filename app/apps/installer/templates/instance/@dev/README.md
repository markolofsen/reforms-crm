# Kanban

One folder per state: `active/` (limit three tracks), `blocked/` (names the blocker and who), `planned/`, `completed/` (with acceptance evidence),
`decisions/` (one short file each), `research/`, `_archive/` (parked, with the reason). A track is a directory with one `PLAN.md`.
English, kebab-case, absolute dates; nothing is deleted.
