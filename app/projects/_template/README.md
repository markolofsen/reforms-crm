# Project template (core)

Layer: **core**. A copy of this folder is the start of a new project; `project-setup` fills `project.md` and `notion-project-deploy` uses `notion-crm/`. It names no real client, domain or person. Real projects live next to it as `app/projects/<slug>/` and are **custom** (one owner's instance, the fork point). Rule: `@docs/LAYERS.md`.
