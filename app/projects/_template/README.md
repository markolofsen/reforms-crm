# Project template (core)

Layer: **core**. A copy of this folder is the start of a new project; `project-setup` fills `project.md` and `notion-crm/` is used by `notion-project-deploy`. `@dev/` is the project's own development kanban: `hub dev init <slug> --apply` copies it to `projects/<slug>/@dev/` (never overwrites). It names no real client, domain or person. Real projects live next to it as `projects/<slug>/` in an instance and are **custom**. Rule: `@docs/LAYERS.md`.
